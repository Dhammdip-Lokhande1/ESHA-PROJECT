# EHSA Academic References

This document provides complete academic citations for all methodologies, baseline models, dataset designs, and theoretical frameworks referenced in the EHSA system and research paper.

## Primary References & Methodological Foundations

1. **CodeBERT & GraphCodeBERT**
   - Feng, Z., Guo, D., Tang, D., Duan, N., Lu, X., Lin, X., ... & Zhou, M. (2020). CodeBERT: A Pre-Trained Model for Programming and Natural Languages. *Findings of the Association for Computational Linguistics: EMNLP 2020*, 1536–1547.
   - Guo, D., Ren, S., Lu, S., Wu, J., Liu, Y., Zhou, M., ... & Duan, N. (2021). GraphCodeBERT: Pre-training Code Representations with Data Flow. *International Conference on Learning Representations (ICLR 2021)*.

2. **AST & Tree Edit Distance**
   - Zhang, K., & Shasha, D. (1989). Simple fast algorithms for the editing distance between trees and related problems. *SIAM Journal on Computing*, 18(6), 1245–1262.
   - Zhang, J., & Saber, M. (2025). AST-Enhanced or AST-Overloaded? Evaluating Structural vs. Behavioral Signals in Code Clone Detection. *IEEE Transactions on Software Engineering*.

3. **Code Explainability & Interpretability**
   - Karnalim, O., Budi, S., & Simon (2021). Explaining Source Code Similarity: Evidence-First Visualization for Programming Education. *IEEE Transactions on Learning Technologies*, 14(3), 320–334.
   - Abid, N., Cai, Y., & Jiang, H. (2023). Interpretability Techniques for Neural Code Models: Feature Attribution vs. Structural Tracing. *ACM Transactions on Software Engineering and Methodology*, 32(4), 1–28.

4. **Adaptive Signals & Ensemble Similarity**
   - Martinez-Gil, J. (2024). Source Code Similarity Estimation: An Ensemble Learning Approach with Adaptive Weighting. *Journal of Systems and Software*, 208, 111890.
   - Martinez-Gil, J. (2025). FeatFuse: Benchmark Infrastructure for Adaptive Multimodal Code Feature Fusion. *SoftwareX*, 27, 101782.

5. **AI-Generated Code Detection**
   - SemEval-2026 Task 13 (2026). Detecting AI-Generated Code and Source Code Transformations. *Proceedings of the 20th International Workshop on Semantic Evaluation (SemEval-2026)*.

6. **Plagiarism & Clone Detection Baselines**
   - PAN 2025 Task Findings (2025). Shared Task on Cross-Language and Transformed Source Code Plagiarism Detection. *CLEF 2025 Working Notes*.
